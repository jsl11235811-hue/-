# 超级玛丽 · 蘑菇王国大冒险

直接双击 `index.html`，用浏览器打开即可游玩。游戏无需安装、无需联网、无第三方依赖；分享时只需发送这一个 HTML 文件。

## 游戏内容

- 四个逐步解锁的世界：阳光草原、地下矿洞、云端漫步、熔岩城堡。
- 横向卷轴、长短跳、加速跑、砖块碰撞、移动平台、悬崖和检查点。
- 栗宝宝、乌龟与可踢出的龟壳、食人花、会跳跃喷火的城堡守卫。
- 金币、超级蘑菇、火焰花、10 秒无敌星星；100 枚金币获得额外生命。
- 通关星级、倒计时奖励、最高分、本地存档、原创合成音效与背景音乐。
- 暂停、重开本关、静音、全屏、手机多点触控手柄。

## 操作

- 移动：`←` / `→` 或 `A` / `D`
- 跳跃：`空格` / `↑` / `W` / `J`，按住跳得更高
- 加速：`Shift` / `X`
- 火球：`Z` / `K`，需要先取得火焰花
- 暂停 / 继续：`P` / `Esc`
- 静音：`M`

触碰终点旗帜即可通关。最后一关需要先击败城堡守卫：踩踏 5 次或命中 8 发火球。守卫受击后有短暂无敌时间。

通关获得 1 颗星，收集至少 45% 的关卡金币再得 1 颗星，剩余至少 170 秒再得 1 颗星。

存档仅保存在当前浏览器中；无痕模式、禁止本地存储或更换文件位置可能影响存档，但不影响游玩。离开页面会暂停游戏。背景音乐在第一次点击开始之后启用。

## 开发验证

安装 Node.js 后，在此目录执行：

```sh
node tests/game.test.cjs
```

测试直接读取 HTML 中的游戏引擎，在隔离环境检查物理、关卡、敌人、道具、通关和存档，不需要安装 npm 依赖。

此项目为非官方致敬小游戏，像素图案与音效均由代码生成，不包含原游戏素材。
